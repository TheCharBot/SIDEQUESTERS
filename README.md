# SIDEQUESTERS

A game all about sidequests  
This is the entire codebase and assets for the DEMO version  
This version is free to be modified in any way, as long as that way is nonconflicting with the release of the full game.  
(eg. scraping the assets from the final game and packaging them with the code of this version)  
This version is meant as a way to make modding the full game be simple and intuitive, but major architecture changes may occur.
